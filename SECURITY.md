# Security Policy

## Supported versions

The `0.1.x` line receives security fixes. Development snapshots are supported until the next tagged release.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's [private vulnerability report](https://github.com/hiwuhgds-pixel/ORDA-Knowledge-Distillation-Kernel/security/advisories/new) when enabled, or email **hiwuhgds@gmail.com** directly. Include affected versions, reproduction steps, impact, and any proposed fix.

Maintainers acknowledge a report within seven days, coordinate disclosure with the reporter, and publish a fixed release and advisory when appropriate.
